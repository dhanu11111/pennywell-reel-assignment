# AI prompts used / reproducible prompts

## Trend research prompt

Identify three current Instagram Reels formats suitable for a personal-finance brand targeting young adults aged 22–35 in India. For each, explain the format, its creative potential and how it can connect naturally to saving money. Do not invent popularity statistics.

## Hook and script prompt

Create ten engaging opening hooks for a 40-second Instagram Reel about building an emergency fund. Select the strongest three. Write a 30–45 second vertical-video script using the "Complete it?" half-heart visual concept. Include timestamps, voice-over, on-screen text, visual direction and a clear call to action. Avoid Diwali or festival references.

## Visual prompt

Create a clean, modern vertical 9:16 visual for a fictional personal-finance brand called Pennywell. Show a simple half-completed heart that gradually becomes complete. Use a minimal background and clear typography. The visual should communicate completing an emergency fund step by step.

## Editing prompt

Edit the Reel for a smooth 40-second Instagram format. Use readable captions, clean transitions and consistent typography. Keep the emergency-fund message clear and avoid unnecessary visual effects.

# Pennywell --- "Complete it?" Reel Assignment

A 40-second, vertical Instagram Reel created for **Pennywell**, a
fictional personal-finance brand.

-   **Concept:** "Complete it?" half-heart text trend
-   **Audience:** Adults aged 22--35 who are new to managing money
-   **Core message:** A small emergency fund can turn unexpected
    expenses into inconveniences. Start by saving one week of expenses.
-   **Video format:** MP4, 9:16 vertical, 1080 × 1920, 30 fps
-   **Video duration:** 40 seconds

## Final video

The final Reel is included in this repository as:

`1000318837.mp4`

The video includes burned-in captions, original synthesized background
music and sound effects, and code-drawn 2D animation.

## Assignment work

The project documentation covers:

1.  Research into three social-media trends, including sources and
    evidence.
2.  Trend scoring and selection. "Complete it?" was selected with a
    score of **35/40**:
    -   Relevance: 9
    -   Freshness: 8
    -   Brand fit: 9
    -   Risk: 9
3.  Creative concept, target audience, tone, visual style and
    guardrails.
4.  Ten hooks, with the top three identified.
5.  Timestamped Reel script, on-screen text, visuals, transitions,
    music/SFX and call to action.
6.  Nine-frame storyboard.
7.  AI image and video prompts for a possible future visual version.
8.  Tools used, challenges and a recreation guide.

## Completion notes and limitations

To keep the submission transparent:

-   **Video:** Created. The README for the original project records a
    40-second, 1080 × 1920, 30 fps MP4 with H.264 video and AAC audio.
-   **Professional voice-over:** Not included. A timed voice-over script
    and SRT captions are provided in the project materials.
-   **AI-generated visuals:** Not used in the current video. The visuals
    are code-drawn 2D animation; AI image/video prompts are provided as
    optional future-production guidance.
-   **Trend evidence:** Trend research and links are documented.
    Screenshots showing dates and engagement should be added if required
    by the recruiter.
-   **Mobile playback QA:** The video should be watched on a phone
    before final submission to confirm that audio, captions, timing and
    transitions display correctly.
-   **GitHub:** This repository is the place to share the uploaded
    project files. Confirm that all intended files have been committed
    before sharing the link.

Do not describe the professional voice-over or AI-generated visuals as
completed features of the current video.

## Rebuild information

The original project README lists the following rebuild steps:

``` bash
pip install -r requirements.txt
bash scripts/build.sh
```

The original build also requires FFmpeg and the Poppins font, with
`FONT_DIR` configured as described in the recreation guide.
